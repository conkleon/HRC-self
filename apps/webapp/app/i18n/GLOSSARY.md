# Greek Glossary

Fixed translations for the app's own terms. Every Greek string uses these, so
a term reads the same on every screen. To change a term, change it here first,
then update every string in `locales/el/` that uses it.

Tone: polite plural (εσείς), short imperative buttons ("Αποθήκευση", not
"Αποθηκεύστε").
